데이터 삭제 안내

시행일 2026-10-19 · 최종 수정일 2026-10-19

MathQuest에는 회원가입·계정이 없습니다. 모든 데이터는 이용자의 기기에만 저장되므로, 아래 방법으로 이용자가 직접 바로 삭제할 수 있습니다. 운영자에게 따로 요청할 필요가 없습니다.

목차

  1. 방법 1. 모든 데이터 삭제 (권장)
  2. 방법 2. 현재 학년 기록만 삭제
  3. 방법 3. 앱 제거
  4. 삭제되는 데이터
  5. 보관 기간
  6. 문의

방법 1. 모든 데이터 삭제 (권장)

  • 앱을 열고 아래쪽 나 탭으로 이동합니다.
  • 관리 항목에서 모든 데이터 삭제를 누릅니다.
  • 전부 삭제를 눌러 확인합니다. 처음 시작 화면으로 돌아갑니다.

방법 2. 현재 학년 기록만 삭제

  • 나 탭 → 관리 → 현재 학년 기록 초기화를 누릅니다.
  • 지금 선택한 학년의 기록만 지워지고 닉네임·아바타·설정과 다른 학년의 기록은 남습니다.

방법 3. 앱 제거

기기 설정 또는 Play 스토어에서 본 앱을 제거하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.

보관 기간

운영자의 서버에 보관되는 데이터가 없으므로, 삭제하는 즉시 영구 삭제되며 별도의 보관 기간이 없습니다. 삭제한 데이터는 복구할 수 없습니다. 기기 백업 기능으로 Google 계정에 백업된 사본은 기기의 Google 백업 설정에서 관리할 수 있습니다.
